# 미미르 스코어 확장: 2026-10-25 적용 범위

사용자 최종 지시를 반영해 **솔로레이드에서 최다 조합과 속성만 가져오고**, 보스별 스탯·패턴을 제외한 공통 전투 조건으로 점수를 계산한다. 우월 코드 효과와 우월 코드 오버로드 옵션을 반영한다.

## 적용 범위

2026-10-19 기존 6종에 다음 8종을 추가해 총 14종을 지원한다.

- 작열: 라피 : 레드 후드, 미하라 : 본딩 체인, 디젤 : 윈터 스위츠
- 수냉: 스노우 화이트 : 헤비암즈, 도로시 : 세렌디피티

- 전격: 신데렐라, 네온 : 비전 아이, 아니스 : 스타

## 계산·화면

- 모든 니케는400레벨·180초·기대값·고정 버스트 게이지·공통 적 스탯으로 계산한다. 보스 속성만 우월 코드에 맞게 달라진다.
- 선택한 니케의 실제 스킬·장비·옵션·돌파·코어·호감도·큐브·소장품·연구실을 전달한다. 동료4명은 고정 육성이다.
- 버스트는 평가 대상의 단계를 우선하고, 쿨타임 중에는 동료를 사용한다. 2단계는 쿨타임이 끝난 동료를 배치 순으로 선택해 교대를 허용한다. 랭킹의 배치 정보와 평가용 버스트 운용을 구분한다.
- 신데렐라·아니스 : 스타는 방어형, 나유타·리틀 머메이드는 지원형, 나머지는 공격형 장비·연구실을 적용한다. 소장품은 MG·SR·RL·SG·SMG·AR별 실제 ID를 사용한다.
- **미미르 스코어 = 개인 딜 × 5 ÷ 1억**. 화면에서만 소수점 둘째 자리까지 반올림한다.
- 웹앱 내부 함수로 자동 계산하고 `미미르 스코어 : 102.24` 형식 한 줄만 표시한다. 딜량 설명·버튼은 없다.
- 라피도 새로운 공통 조건으로 통일했다. 기존 S40 패턴 기준102.19점과 현재 기준은 다르다.

## 구현 구조

`targets.json` → 캐릭터별 정규화 → 개별 `calculate_*_score` → 고정 조합 전투 → 점수.

대상 목록을 Dart로 생성해 상세 화면에 연결했다. 엔진과14종 함수·환경은 약13.6MB의 자체 제공 웹 런타임에 포함한다. 별도 계산 서버를 호출하지 않는다. 기존 계정 동기화·속성별 통계 점수·전투력 계산은 유지한다.

검증은14종 모두에 대해 입력 ID·장비 역할군·연구실·무기별 소장품, 동일 공통 적 조건, 코어 강화에 따른 점수 상승, 우월 옵션 제거에 따른 하락, Chrome WASM과 Python의 점수 일치, 화면 자동 계산·이전 응답 무시·한 줄 표시를 포함한다.

버스트 사용0회로 신데렐라·홍련 : 흑영의 점수가 과소 산정되던 오류와 크리스탈 웨이브 조합의 2단계 교대 누락을 수정했다. 실제 전투 로그에서 대상 버스트·2단계 동료 교대·풀버스트 횟수를 검증하도록 보강했다. 당시 합성 기준 입력의 기존 여섯 대상 모두 버스트8회, 풀버스트15회다.

자세한 조합·버전·실행 명령은 [계산기 README](../services/nikke_score/README.md)에 정리했다. 현재 코드는 웹용이며 운영 사이트 배포와 실전 대조는 수행하지 않았다.
